# Sources sonores

Les 32 fichiers ci-dessous sont des créations sonores synthétisées pour ce projet par l’assistant OpenAI, à l’aide du script original `scripts/generate_audio.py`. Aucun échantillon, enregistrement, musique ou fichier externe n’a été utilisé. La tentative de recherche via l’API Wikimedia Commons a été bloquée par les restrictions réseau de l’environnement ; aucune licence externe n’a donc été présumée.

Origine : synthèse procédurale originale (sinusoïdes, bruit, enveloppes). Auteur : génération automatisée pour ce projet, sans auteur d’enregistrement tiers. URL source : sans objet (création locale). Licence tierce : sans objet. Les fichiers créés pour cette livraison sont mis à disposition sans exigence d’attribution, dans la mesure des droits applicables ; cette mention ne prétend pas certifier une licence CC0 provenant d’un tiers.

Tous les effets organiques sont des interprétations stylisées. Le cri théâtral est une alternative originale au cri Wilhelm, sans utilisation de cet enregistrement.
